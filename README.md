# 选题情报

每日自动搜集数据行业与金融行业过去24小时的核心动态，生成结构化情报页面并邮件推送，完全跑在 GitHub Actions 云端，与本机是否开机无关。

## 数据来源

- **36氪 RSS**（数据/科技行业深度报道，免费无需Key）
- **newsnow 聚合接口**（社区维护的免费热榜聚合站，覆盖华尔街见闻、财联社、金十数据的财经快讯，以及微博、百度热搜）
- **Yahoo Finance**（相关公司实时行情，免费无需Key）

## 四个板块

1. **今日热点选题**：微博/百度热搜中与数据/金融/科技相关的条目（不足时用36氪补充）
2. **行业趋势速览**：36氪 + 财经快讯中的行业趋势类内容
3. **核心数据汇总**：包含具体数字/统计口径的条目（同比、环比、亿元等）
4. **相关股票行情与关注建议**：扫描前三板块提到的约18家常见公司（英伟达、苹果、腾讯、宁德时代等），查实时涨跌幅，按机械规则给出关注建议（涨跌幅≥2%为"重点关注"，≥1%为"建议关注"，多条新闻提及但涨跌不大为"建议关注：多条新闻提及"，否则"一般关注"）

内容为纯脚本关键词匹配+数据拼接生成，不经过AI改写，风格偏机械，完全免费。

## 触发时间

纽约时间每个工作日 7:30，通过 cron-job.org 精准调用 GitHub API 触发（不用 GitHub 自带的 schedule，原因见财经简报项目的踩坑记录——GitHub 自带定时器不可靠）。

## 目录结构

- `lib/`：共用模块（36氪/newsnow抓取、Yahoo行情、发邮件、关键词匹配）
- `scripts/generate_report.py`：主脚本
- `选题情报.html`：最新一期报告（每天覆盖）
- `reports/`：历史报告归档（按日期）
- `.github/workflows/daily-intel.yml`：GitHub Actions 配置（只保留 workflow_dispatch，由外部 cron-job.org 触发）

## 手动触发测试

在 GitHub 仓库 Actions 页面选择 "Daily Topic Intelligence"，点击 "Run workflow"，勾选 `force` 可跳过时间窗口检查直接执行。
